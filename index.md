## 🚨 Troubleshooting 

If you encounter any issues while using GitHub-Wrapped, here are some common problems and solutions:

- **Unable to Connect to GitHub**:
  - Check your internet connection.
  - Make sure your GitHub account has API access enabled.

- **Data Not Showing Up**:
  - Ensure you have made commits in the past year.
  - Reconnect your GitHub account if necessary.

- **Crashes or Unresponsive Application**:
  - Ensure you have the latest version installed.
  - Restart your device and try again.
